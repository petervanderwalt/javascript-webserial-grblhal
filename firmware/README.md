Place the firmware payloads for the flashing modal in this directory:

- `bootloader.bin`
- `partitions.bin`
- `firmwarez1.bin`
- `firmwarez2.bin`
- `firmwareactuator.bin`

`bootloader.bin` and `partitions.bin` are bundled here already. The three machine-specific firmware images must be provided before the new flashing flow can complete successfully.
